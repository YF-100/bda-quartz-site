### Issue: Out of memory during LR training

**Symptom**: `java.lang.OutOfMemoryError`

**Solution**:
```python
# Reduce shuffle partitions
spark.conf.set("spark.sql.shuffle.partitions", "2")

# Or increase executor memory (restart Spark)
spark.stop()
spark = SparkSession.builder \
    .config("spark.executor.memory", "2g") \
    .config("spark.driver.memory", "2g") \
    .getOrCreate()
```

### Issue: Dataset download fails

**Symptom**: `urllib.error.URLError`

**Solution**:
- Manual download from UCI: https://archive.ics.uci.edu/ml/datasets/SMS+Spam+Collection
- Extract and place in `data/sms.tsv`
- Format: tab-separated, no header

### Issue: PPR scores don't sum to 1.0

**Symptom**: `total_mass != 1.000000`

**Solution**:
- Expected behavior: normalization should enforce sum=1.0
- Small deviations (<0.001) are acceptable due to floating-point precision
- Large deviations indicate implementation bug
